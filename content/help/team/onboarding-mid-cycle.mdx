# Onboarding New Hires Mid-Cycle

<RoleTag role="hr" /> <RoleTag role="admin" />

When a new team member joins while a review cycle is already in progress, you have a few options to integrate them smoothly.

## Adding a New Hire to an Active Cycle

1. First, add the new hire to Perf via **Dashboard > Team > Add Member** or CSV import.
2. Navigate to the active cycle and click **Manage Participants**.
3. Add the new hire to the participant list.
4. Assign their manager and peers.

<Callout type="info">
New participants added mid-cycle will only participate in phases that have not yet started. If the Self Assessment phase has already closed, they will skip it and begin with the next open phase.
</Callout>

## Setting Up a Probation Review

For new hires who need a structured evaluation during their trial period:

1. Create a separate **Probation** cycle scoped to just the new hire (or a batch of new hires).
2. Use the probation template, which focuses on onboarding competencies and initial role expectations.
3. Set a timeline that aligns with your organization's probation period (typically 30, 60, or 90 days).

<Callout type="tip">
Probation cycles work independently from your main review cycle. You can run both simultaneously without conflict.
</Callout>

## What Happens If They Join Late

If a new hire is added after several phases have closed:

- They will not have self-assessment or peer review data for this cycle.
- Their manager can still complete a manager review covering the period the employee was present.
- In calibration, flag these individuals so leadership knows the data set is incomplete.

<Callout type="warning">
Avoid rating new hires with less than 4 weeks in-role against the same scale as tenured employees. Use qualitative notes instead or defer to the probation cycle.
</Callout>
